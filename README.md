# Employee Management System

## Project Overview
The Employee Management System is a menu-driven Python application developed using Object-Oriented Programming (OOP) concepts. It helps manage employee and manager records efficiently, with automated salary calculations and bonus structures.

## Features
- Add new employee records
- Display employee details
- Search employee records
- Update employee information
- Delete employee records
- Manage employee and manager details
- Calculate salaries with different bonus structures

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## OOP Concepts Implemented
- Classes and Objects
- Inheritance
- Encapsulation
- Method Overriding

## How to Run
1. Clone or download this repository.
2. Make sure Python is installed on your system.
3. Open the project folder in your code editor or terminal.
4. Run the Python file:

```bash
python main.py
```
